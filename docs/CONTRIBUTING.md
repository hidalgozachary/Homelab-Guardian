# Contributing to Homelab Guardian

Thank you for contributing to Homelab Guardian.

The project values reliability, clarity, maintainability, and operational safety.

## Development Workflow

1. Start from an updated `main` branch.
2. Create a focused branch.
3. Make one logical change at a time.
4. Add or update tests.
5. Run the complete test suite.
6. Update documentation when necessary.
7. Create clear commits.
8. Open a pull request.

## Branch Naming

Use descriptive branch names.

Examples:

```text
feature/discord-notifications
feature/unraid-storage-collector
fix/discord-timeout-handling
refactor/package-architecture
docs/update-deployment-guide
